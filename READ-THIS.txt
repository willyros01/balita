WHAT WAS ACTUALLY WRONG
Confirmed directly from the trace file you sent, not guessed. Pageshow
fired early, before the app's own startup had finished loading settings
and the full story list. Because the notification check has its own
way of fetching one story directly, it did not need to wait, and it
opened your article successfully, fast.

Moments later, the app's own slower startup finished its work, and
unconditionally sent the screen back to the main feed - every time,
regardless of what was already showing. That is what erased the
article you had just opened.

THE FIX
One line. Startup now only shows the main feed if an article is not
already open. If one is, it leaves it alone.

The trace stays in for this round, so the fix can be confirmed the
same way the problem was found - by reading exactly what happened,
not by assuming it worked.

HOW TO TEST
Delete and re-add the Home Screen icon. Clear the trace. Send a test
alert. Tap it. If it opens correctly and stays open, save the trace
anyway and send it - a clean, confirming trace is worth having on
record too.
