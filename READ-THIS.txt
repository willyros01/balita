WHAT'S DIFFERENT FROM v0.17.35
Nothing about how notifications actually work has changed. This adds
only a small recording of what happens, so the one still-unexplained
case — the iPad landing on All Sources after a cold-start tap — can be
seen directly instead of reasoned about.

HOW TO USE IT
Two small buttons now sit at the very bottom of the About panel, under
a heading that says "Notification trace (temporary)":

  Save trace as a file
  Clear trace

Tap Clear trace before a test, run the test, then tap Save trace as a
file afterward. On an iPad or iPhone this should offer to save a file
called wire-trace.txt, or open a share sheet — either way, save it
somewhere you can get to it, then attach that file here in the chat
directly. No screenshots needed this time.

HOW TO TEST
Delete and re-add the Home Screen icon on whichever device you are
testing. Clear the trace. Send a test alert. Tap it. Save the trace
file. Send it here.

If the About panel does not show the two buttons at all after
updating, the new files did not take — check the Version line first.
